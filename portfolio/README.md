# Portfolio Website

This folder contains the portfolio website files.

## Structure:
- `index.html` - Main HTML file
- `style.css` - CSS styling
- `script.js` - JavaScript functionality

## Add Your Files:
Place your portfolio website files here to deploy them on GitHub Pages.

## Access:
Once deployed, your portfolio will be available at: `https://vexedpainter.github.io/VexedPainter/portfolio/`
